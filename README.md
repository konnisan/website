# Konni Pixel Alchemy

Personal homepage project built with Next.js/Vinext and a pixel-art alchemy theme.

## Local development

```bash
pnpm install
pnpm dev
```

Requires Node.js >= 22.13.0 and pnpm 11.x.

## Build

```bash
pnpm build
```

The current project uses Vinext/Cloudflare tooling and can be deployed as a Cloudflare Worker/Pages-style application after building.
